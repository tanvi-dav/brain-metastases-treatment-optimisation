# NeurIPS 2025 Project

## Overview
This repository contains the code and models for our NeurIPS 2025 submission on clinical data analysis using transformer models.

## Project Structure
```
├── data/
│   └── imaging/          # Patient imaging data (not tracked in git)
├── metadata/             # Processed data files (not tracked in git)
├── model/
│   └── transformer_model # Main transformer model implementation
└── requirements.txt      # Python dependencies
```

## Setup

1. Clone the repository:
```bash
git clone <repository-url>
cd NeurIPS2025
```

2. Create and activate a virtual environment:
```bash
python -m venv .venv
source .venv/bin/activate  # On macOS/Linux
# or
.venv\Scripts\activate     # On Windows
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the transformer model:
```bash
python model/transformer_model
```
